# GitHub Upload Checklist

Before making the repository public, verify:

- [ ] No dataset CSV is committed.
- [ ] No `.class`, `.jar`, `.zip`, or build output files are committed.
- [ ] No student ID or private personal metadata remains.
- [ ] `data/README.md` explains where to place the dataset.
- [ ] `README.md` explains how to compile and run the project.
- [ ] Generated plots are not committed unless intentionally added as documentation.
