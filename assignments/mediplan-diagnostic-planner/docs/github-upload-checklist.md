# GitHub Upload Checklist

Before making the repository public, verify:

- [ ] The original assignment PDF is not included.
- [ ] The original submission ZIP is not included.
- [ ] No student ID or personal information is present in file names or source comments.
- [ ] No `.class`, `.jar`, or IDE-generated files are committed.
- [ ] The assignment appears under `assignments/mediplan-diagnostic-planner/`.
- [ ] The root `README.md` includes this assignment in the project table.
- [ ] The project compiles with `make compile` or `javac -d bin src/*.java`.
