# CV Bullets

## English

**MediPlan Diagnostic Planner — Java 11, Dynamic Programming**

- Implemented a diagnostic planning system that models medical tests as a dependency graph parsed from XML input files.
- Used top-down memoized dynamic programming to compute patient burden based on distinct physical sample collection procedures.
- Built a bottom-up tabulation DP pipeline with DFS-based topological ordering to compute naive hospital costs for multiple diagnostic targets.
- Constructed optimized diagnostic execution plans that eliminate repeated work by counting each reachable test exactly once.

## Turkish

**MediPlan Diagnostic Planner — Java 11, Dinamik Programlama**

- XML girdilerinden okunan tıbbi testleri dependency graph olarak modelleyen bir diagnostic planning sistemi geliştirdim.
- Fiziksel numune toplama prosedürlerini temel alarak hasta yükünü hesaplamak için top-down memoized dynamic programming uyguladım.
- Birden fazla hedef tanı skoru için naive hospital cost hesaplayan DFS tabanlı topological ordering ve bottom-up tabulation DP hattı geliştirdim.
- Ortak bağımlılıkları tekrar hesaplamadan, her testi en fazla bir kez sayan optimize edilmiş diagnostic execution plan oluşturma mantığı geliştirdim.
