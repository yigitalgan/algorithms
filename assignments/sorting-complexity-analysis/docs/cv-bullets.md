# CV Bullets

## English

**Sorting Algorithm Complexity Analysis — Java 11**

- Implemented Quick Sort, Insertion Sort, Merge Sort, Shell Sort, and Radix Sort in Java for empirical complexity analysis.
- Benchmarked sorting performance on stock-market volume data across random, sorted, and reversely sorted input distributions.
- Measured average running times over repeated experiments for input sizes ranging from 500 to 250,000 records.
- Generated timing tables and plots to compare empirical performance against theoretical time and auxiliary-space complexities.
