# GitHub Upload Checklist

Before making the repository public:

- Confirm that no original assignment PDF is uploaded.
- Confirm that no original submission ZIP is uploaded.
- Confirm that no `.class`, `.jar`, or build output files are uploaded.
- Confirm that no student ID or personal submission metadata appears in source files.
- Confirm that the assignment is under `assignments/astranova-spaceport-planner/`.
- Confirm that the root README lists this project correctly.
- Run the sample locally if desired:

```bash
cd assignments/astranova-spaceport-planner
make run
```
