# Problem Summary

The Aetheria Project is a graph algorithms assignment built around a smart-city infrastructure scenario.

## Components

- **Power Grid:** Determine whether all districts are connected and compute a minimum spanning tree for minimum cable cost.
- **Master Boot Sequence:** Generate a valid topological ordering for dependent city systems and detect deadlocks caused by cycles.
- **Secure Communication Hubs:** Identify strongly connected components in a directed fiber network and report high-interaction zones.
- **Bio-Leak Containment:** Use DFS to find every station reachable from a source and BFS to group stations by minimum hop distance.

## Algorithms Used

- DFS
- BFS
- Kruskal minimum spanning tree
- Union-find
- Topological sorting
- Cycle detection
- Strongly connected components
