# Algorithms Assignments

Selected algorithms assignments implemented in Java during computer engineering coursework.

This repository contains algorithm-focused programming assignments covering empirical complexity analysis, dynamic programming, graph algorithms, shortest path computation, graph-based scheduling, XML parsing, and regular-expression based input parsing.

## Projects

| Assignment | Project | Language | Key Concepts |
|---|---|---|---|
| 01 | [Sorting Complexity Analysis](assignments/sorting-complexity-analysis) | Java 11 | Sorting algorithms, empirical runtime analysis, asymptotic complexity, benchmarking, plotting |
| 02 | [MediPlan Diagnostic Planner](assignments/mediplan-diagnostic-planner) | Java 11 | Dynamic programming, dependency graphs, memoization, tabulation, topological ordering, XML parsing |
| 03 | [Aetheria Smart City Graph Algorithms](assignments/aetheria-smart-city-graph-algorithms) | Java 11 | Graph connectivity, minimum spanning tree, topological sort, cycle detection, strongly connected components, BFS/DFS |
| 04 | [AstraNova Spaceport Planner](assignments/astranova-spaceport-planner) | Java 11 | Shortest path, graph-based scheduling, prerequisite constraints, route planning, regular expressions |
